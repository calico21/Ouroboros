# Strategy 10: positive_gamma_pin_fade (Sleeve E: Bounded Mean Reversion)
## Mechanism
Exploits dealer long-gamma hedging (buying dips, selling rallies) to fade excursions around max-gamma pin strike.
## Window & Execution
- 10:30–15:15 ET. Fades 0.35%–0.50% excursions from pin strike.
- SL 25–30 pts beyond entry. Target: Max-gamma pin strike. Sizing: 1 MNQ.
